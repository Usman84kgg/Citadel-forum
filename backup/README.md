# Резервные копии CITADEL

## Важное правило безопасности

В этой папке хранится структура и правила резервного копирования.
Сами файлы копий в репозиторий не загружаются — это запрещено
настройками .gitignore и сделано намеренно.

Причина: копия базы данных содержит электронные почты участников,
хэши паролей, адреса криптокошельков и историю финансовых операций.
Такие данные не должны храниться в системе контроля версий.

Готовые копии хранятся в облачном хранилище и в защищённой папке телефона.

---

## Назначение подпапок

| Папка | Что хранится |
|---|---|
| database/ | Копии базы данных: пользователи, форум, сделки, финансовый журнал |
| uploads/ | Копии загруженных файлов: аватары, вложения, доказательства по спорам, реклама |
| settings/ | Копии настроек платформы: комиссии, лимиты, тексты страниц, шаблоны писем |

## График резервного копирования

| Что | Как часто | Способ | Хранить |
|---|---|---|---|
| База данных | Ежедневно | Автоматически провайдером | 7 дней |
| База данных | Еженедельно | Вручную с телефона | 3 месяца |
| Загруженные файлы | Еженедельно | Автоматическая задача | 1 месяц |
| Настройки платформы | При изменении | Экспорт из админ-панели | Постоянно |
| Код проекта | Постоянно | GitHub | Постоянно |

---

## Как сделать копию базы данных с телефона

1. Открыть панель управления базой данных в браузере
2. Раздел Database → Backups
3. Нажать Download у нужной даты
4. Файл сохранится в загрузки телефона
5. Перенести его в защищённое облако в папку CITADEL / backups
6. Не загружать этот файл в GitHub

---

## Как сделать копию настроек

1. Админ-панель → Настройки → Экспорт настроек
2. Скачать файл настроек
3. Сохранить в облако в папку CITADEL / settings

---
