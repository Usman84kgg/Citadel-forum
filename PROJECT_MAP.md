## 2. Путь пользователя: Форум

Главная → Форум → Категории → Темы → Сообщения

Правила доступа:
- Гость видит список разделов и часть тем, но не может писать
- Участник после подтверждения почты создаёт темы и отвечает
- Раздел VIP доступен только участникам со статусом VIP
- Новые аккаунты первое время ограничены в публикации ссылок

---

## 3. Путь пользователя: Гарант

Гарант → Создание сделки → Оплата → Арбитраж (при споре) → Завершение сделки

### Состояния сделки

| Состояние | Что означает | Где деньги |
|---|---|---|
| Черновик | Создана, не отправлена | Не задействованы |
| Ожидает подтверждения | Отправлена второй стороне | Не задействованы |
| Ожидает оплаты | Условия приняты обеими сторонами | Не задействованы |
| Средства заморожены | Покупатель оплатил | Заморожены платформой |
| В работе | Исполнитель приступил | Заморожены |
| Выполнено | Результат передан покупателю | Заморожены |
| Спор | Открыт спор | Заморожены |
| Арбитраж | Назначен сотрудник платформы | Заморожены |
| Завершена | Подтверждено или истёк срок | Переведены продавцу |
| Возврат покупателю | Решение арбитра | Возвращены покупателю |
| Разделено | Частичный возврат по решению | Разделены |
| Отменена | До оплаты | Не задействованы |

### Ключевые правила
- Минимальная сумма сделки: 10 USD
- Комиссия платформы: 2%
- Срок рассмотрения спора: до 72 часов
- Средства заморожены до завершения и недоступны для вывода
- Отзыв возможен только после завершённой сделки

## 4. Путь пользователя: Маркет

Маркет → Категории → Объявления → Отзывы

- Новое объявление проходит проверку модератором
- Заказ услуги автоматически создаёт сделку в разделе Гарант
- Отзыв привязан к завершённой сделке

---

## 5. Путь пользователя: Кошелёк

### Пополнение
Заявка → Система выдаёт адрес и код → Пользователь переводит криптовалюту
и указывает TXID → Администратор проверяет → Баланс пополнен

### Вывод
Заявка → Подтверждение через 2FA и PIN → Средства заморожены →
Администратор отправляет выплату и указывает TXID → Средства списаны

Правила:
- Основная валюта учёта: USD
- Приём средств: BTC и USDT (TRC20)
- Новый адрес вывода проходит карантин 24 часа
- Все операции проводятся вручную администратором на старте

## 6. Роли пользователей

| Роль | Что может |
|---|---|
| Гость | Просмотр публичных разделов |
| Новичок | Базовые действия с ограничениями |
| Участник | Полный доступ к форуму, маркету, сделкам |
| VIP | Закрытый раздел, сниженная комиссия, приоритет поддержки |
| Проверенный продавец | Повышенные лимиты, знак верификации |
| Поддержка | Работа с тикетами |
| Модератор | Модерация контента, предупреждения |
| Старший модератор | Управление модерацией |
| Арбитр | Рассмотрение споров и решения |
| Финансист | Подтверждение пополнений и выплат |
| Администратор | Управление платформой |
| Владелец | Полный доступ |
