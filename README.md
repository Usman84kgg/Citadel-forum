# CITADEL — Private Community Platform

Премиальная закрытая платформа: форум, безопасные сделки через гаранта,
внутренний баланс, маркетплейс услуг, система репутации и административная панель.

---

## Что входит в платформу

| Раздел | Назначение |
|---|---|
| Главная | Приветственный блок, статистика, объявления, топ пользователей, последние сделки |
| Форум | Категории, разделы, темы, сообщения, реакции «Спасибо», закрытый VIP-раздел |
| Пользователи | Профили, репутация, достижения, статус онлайн |
| Гарант | Безопасные сделки с заморозкой средств до подтверждения выполнения |
| Маркет | Объявления и услуги участников с модерацией |
| Кошелёк | Баланс, пополнение и вывод в криптовалюте, история операций |
| Ресурсы | Полезные материалы, инструменты, руководства |
| Поддержка | Тикеты с приоритетами и сроками ответа |
| Админ-панель | Отдельный поддомен: пользователи, финансы, споры, реклама, настройки |

---

## Технологии

| Слой | Решение |
|---|---|
| Интерфейс и сервер | Next.js (App Router), React, TypeScript |
| Оформление | Tailwind CSS + дизайн-токены CITADEL |
| База данных | PostgreSQL + Prisma |
| Хранение файлов | S3-совместимое хранилище через адаптер |
| Почта | Транзакционные письма через адаптер |
| Кэш и лимиты | Redis через адаптер |
| Фоновые задачи | Очередь задач в базе данных + запуск по расписанию |
| Поиск | Полнотекстовый поиск PostgreSQL |
| Защита периметра | Cloudflare (DNS, SSL, WAF, DDoS) |

Все внешние сервисы подключены через адаптеры. Переезд на собственный VPS
выполняется сменой переменных окружения — без переписывания кода.

## Структура репозитория

- `.github/workflows/` — автоматические проверки кода и фоновые задачи
- `backup/` — резервные копии: `database/`, `uploads/`, `settings/`
- `design/` — исходники оформления: `logos/`, `backgrounds/`, `banners/`, `forum-assets/`, `screenshots/`
- `docs/` — пошаговые инструкции по проекту
- `prisma/` — схема базы данных и миграции
- `public/` — файлы, отдаваемые сайтом
- `src/app/` — страницы: публичные, участников, админки
- `src/server/` — серверная логика по модулям
- `src/components/` — дизайн-система и блоки интерфейса
- `src/messages/` — переводы: русский и английский
- `src/styles/` — цвета, шрифты, тени
- `src/lib/` — вспомогательные функции
- `docker/` — запуск на собственном VPS
- `PROJECT_MAP.md` — карта проекта

## Принципы безопасности

- Ни один пароль, ключ или адрес кошелька не хранится в коде
- Адреса для пополнения хранятся в базе в зашифрованном виде
  и управляются только через административную панель
- Все операции с деньгами записываются методом двойной записи
  в журнал, который невозможно изменить задним числом
- Обязательная двухфакторная аутентификация для персонала
  и для вывода средств
- Полный журнал действий администраторов
- Репозиторий приватный
