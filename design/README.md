# Оформление CITADEL

Архив исходных материалов оформления платформы.

Разница между папками:
- design/ — архив исходников, хранится для истории и повторного использования
- public/ — рабочие файлы, которые реально отдаёт сайт посетителям

Логотип хранится в обоих местах: оригинал в design/logos/,
оптимизированная версия в public/logo/.

---

## Назначение подпапок

| Папка | Что хранить |
|---|---|
| logos/ | Логотип CITADEL: полный вариант с надписью, только герб, иконки |
| backgrounds/ | Фоны страниц, текстуры, градиенты, изображение замка |
| banners/ | Баннеры главной страницы, обложки разделов, рекламные шаблоны |
| forum-assets/ | Иконки разделов форума, значки ролей, награды, рамки аватаров |
| screenshots/ | Макеты интерфейса и скриншоты готовых страниц |

---

## Правила именования файлов

Только латиница, строчные буквы, дефис вместо пробела.

Правильно:
logo-full-gold.png
logo-shield-only.png
bg-castle-hero.jpg
icon-section-market.svg
badge-vip.svg
screenshot-homepage-v1.png

Неправильно:
Логотип финал.png
IMG_20240115_итог(2).jpg

## Форматы и размеры

| Назначение | Формат | Размер |
|---|---|---|
| Логотип полный | PNG с прозрачностью | 1200 x 1200 |
| Логотип в шапке сайта | SVG или PNG | высота 48 px |
| Иконка сайта | PNG | 512 x 512 |
| Иконки разделов форума | SVG | 64 x 64 |
| Фон приветственного блока | JPG или WebP | 1920 x 800 |
| Баннер главной страницы | JPG или WebP | 1600 x 400 |
| Баннер боковой колонки | JPG или WebP | 600 x 600 |
| Значки и награды | SVG | 48 x 48 |
| Скриншоты | PNG | как есть |

## Шрифты

| Шрифт | Применение |
|---|---|
| Cinzel | Логотип, слово CITADEL, заголовки разделов |
| Inter | Весь остальной интерфейс |

Оба шрифта бесплатны и подключаются автоматически.

## Что загрузить в первую очередь

1. logos/ — логотип со щитом, короной и надписью CITADEL
2. backgrounds/ — изображение замка из приветственного блока
3. screenshots/ — макет главной страницы

Способ загрузки: открыть нужную папку → Add file → Upload files →
выбрать изображение из галереи телефона → Commit changes.
