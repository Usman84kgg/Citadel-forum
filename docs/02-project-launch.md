# Фаза 2 — технический каркас

## Что создано

- `package.json` — список библиотек
- `tsconfig.json` — строгая проверка кода
- `next.config.ts` — заголовки безопасности
- `tailwind.config.ts` — палитра CITADEL
- `.env.example` — образец ключей
- `.github/workflows/ci.yml` — автопроверка
- `src/styles/tokens.css` — все цвета
- `src/app/globals.css` — базовые стили
- `src/lib/config/site.ts` — название, комиссия 2%, мин. 10 USD, споры 72ч
- `src/app/layout.tsx` — оболочка страниц, шрифты Cinzel + Inter
- `src/app/page.tsx` — временная заставка
- `src/app/not-found.tsx` — страница 404
- `src/app/error.tsx` — страница при сбое

## Результат проверки

| Значок | Что значит | Действие |
|---|---|---|
| Жёлтый кружок | Идёт проверка | Подождать 3–4 минуты |
